1. Objectives:

To design and develop an interactive College Fest 2026 event website.

To provide students with information about various college fest events.

To display event dates, timings, venues, and descriptions.

To allow students to register for events online.

To provide an organized event schedule for participants.

To create an attractive gallery section to showcase college fest activities.

To provide contact information for students and participants.

To develop a responsive website that works on desktops, tablets, and mobile devices.

To implement JavaScript for event selection and form handling.

2. Tools and Techniques:

Tool / Technology	Purpose

HTML5	Creates the structure of the College Fest website

CSS3	Provides styling, colors, layouts, and animations

JavaScript	Adds interactivity and form functionality

VS Code	Used for writing and editing the code

CSS Flexbox	Used for navigation bar and content alignment

CSS Grid	Used for event cards and gallery layout

Media Queries	Makes the website responsive

HTML Forms	Used for event registration

DOM Manipulation	Handles user interaction and form data

Event Listeners	Handles user actions

Unsplash Images	Provides event and gallery images

Smooth Scrolling	Enables smooth navigation between sections

3. Features:

1. Navigation Bar

The website contains navigation links for:

Home

Events

Schedule

Register

Gallery

Contact


The navigation bar remains visible at the top while scrolling.

2. Announcement Section

Displays an important notification:

> 📢 College Fest 2026 registration is now open!



3. Home Section

The homepage displays:

COLLEGE FEST 2026

Theme: Celebrate • Compete • Connect

Introduction to the college festival

Explore Events button


4. Event Listings

The website provides six different events:

Tech Quiz

Music Fest

Sports Championship

Dance Competition

Gaming Challenge

Coding Challenge


Each event contains:

Event image

Event name

Date

Time

Description

Register button


5. Event Schedule

A table displays:

Date

Time

Event

Venue


This helps students easily understand the complete event schedule.

6. Event Registration

Students can enter their details through a registration form, such as:

Full Name

Email Address

Selected Event

Other required information


7. Gallery

The gallery section can display photographs from the college fest using a responsive image grid.

8. Contact Section

Provides contact information so participants can communicate with the event organizers.

9. Responsive Design

The website automatically adjusts its layout according to screen size:

Desktop

Tablet

Mobile


10. Interactive Design

The website includes:

Hover effects

Animated buttons

Event selection

Smooth scrolling

Responsive cards

Interactive registration
